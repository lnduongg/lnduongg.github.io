# Luyen Ngoc Duong — Developer Portfolio

A static, responsive portfolio site using **HTML, CSS and JavaScript**, featuring the Unity game **You Hear That?**.

## Run locally

Open `index.html` in your browser. For a development server, open a terminal in this folder and run:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Publish to GitHub Pages

1. Create a **new public repository** named `lnduongg.github.io` under the GitHub account `lnduongg`.
2. Upload **all contents of this folder** to the repository root. `index.html` must be at the root.
3. Open repository **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, set `main` and `/(root)`, then Save.
4. Once GitHub Pages finishes deployment, your website should be at **https://lnduongg.github.io/**.
5. Test links and images, then put that URL on your CV and GitHub profile.

If you use a repository with a different name, the URL will generally be `https://lnduongg.github.io/REPOSITORY-NAME/`.

## Customize

- `index.html`: main portfolio content and extra projects.
- `project.html`: technical case study.
- `styles.css`: colors, typography, spacing and responsive styles.
- `script.js`: mobile navigation and subtle section animations.
- `assets/images/`: real project screenshots sourced from the supplied graduation report.
- `assets/files/Luyen_Ngoc_Duong_CV.pdf`: CV, replace when updating your resume.

Current game download: https://lnduongg.itch.io/you-hear-that. Game language is Vietnamese only.
